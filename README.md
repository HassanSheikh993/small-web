# The Small Web

Needs Node.js 20+ and MongoDB running on `localhost:27017`.

## Backend (http://localhost:4000)

```bash
cd backend
cp .env.example .env
npm install
npm run seed
npm run start:dev
```

## Frontend (http://localhost:3000)

```bash
cd frontend
npm install
npm run dev
```

Open http://localhost:3000 and pick a name.
